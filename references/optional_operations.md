# 可选操作：角色替换 / 动作迁移 / 音色替换

本技能**默认做 1:1 完整复刻**（原角色、原场景、原动作、原音频、原镜头）。以下三项是**可选**变换，必须**在开工前问用户**，问清楚再动手——做错方向会浪费整条生成链路的时间。

---

## 开工前的门控询问（不可跳过）

在抽帧分析之后、写任何提示词之前，**必须问用户是否要做这三项操作**。用结构化提问工具给出可多选的选项，并把"1:1 完整复刻"作为默认项摆出来。

建议选项（多选）：

| 选项 | 含义 |
|---|---|
| **都不做 —— 1:1 完整复刻**（默认） | 原角色 / 原场景 / 原动作 / 原音频，逐镜照搬 |
| **角色替换** | 换掉画面里的角色，保留动作、镜头、场景、台词 |
| **动作迁移** | 换掉角色的动作，保留角色、场景、镜头 |
| **音色替换** | 换配音音色，保留台词内容、时间码、画面 |
| **场景替换** | 换场景环境，保留角色、动作、镜头 |

**用户没回答、或回答含糊时，一律按默认的 1:1 复刻执行**，并在交付说明里写明"按默认 1:1 复刻执行；如需角色/动作/音色/场景变换请告知"。

确定后把结果写进交付物开头的"复刻模式"一行，后续所有描述与提示词都以此为准。

---

## 默认模式：1:1 完整复刻

**这是默认，也是不需要额外输入的唯一模式。**

- **角色**：资产库里的角色参考图**全部从源片抽取**，不引入任何外部素材
- **场景**：同上
- **动作**：过渡描述逐条照搬源片的运动
- **音频**：直接复用源片音轨
  - 源片**有**音轨 → 裁切/循环对齐到成片长度（跨段重复用短音轨时，接缝处做交叉淡化）
  - 源片**无**音轨 → 没有"原音频"可复用，只能保留模型生成的音频；需要配音时另行走音色流程
- **镜头**：运镜描述照搬

---

## 一、角色替换

**改什么**：画面里角色的身份（外观）。
**保留什么**：动作时序、镜头运动、构图、场景、台词内容与时间码、每段时长。

### 需要的输入

- 新角色的**资产图**（正面立绘或三视图）+ 一段固定外观描述
- 明确哪些角色要换、哪些保留（多角色场景必须逐个确认）

### 技术路径

1. **资产库层面**：把 CH-01（源片角色）**替换**为 CH-01'（新角色）。参考图用新角色的立绘，固定描述换成新角色描述。
2. **提示词层面**：
   - **整体替换**所有角色外观描述（体型、发型、服饰颜色与形制、配饰、特征物）
   - **逐字照抄**动作、镜头、场景、构图、光线、对话描述 —— 一个词都别改
   - 引用槽位指向新的角色资产
3. **台词**：保留原台词时，内容与时间码不动（音色由音色流程单独处理）。
4. **音画关系**：角色替换会让原片的口型与新角色不匹配。若画面有清晰口型，要么接受、要么改用背对/侧脸构图规避。

### 验证要点

- 逐镜核对新角色外观**前后一致**（同款服饰、同发型、同体型）
- 动作时序与原片**逐段对齐**（时长不变）
- 没有出现"新旧混搭"（例如换了脸但还穿着原角色的衣服）

### 常见风险

| 风险 | 表现 | 规避 |
|---|---|---|
| 身份漂移 | 换脸换到一半变成另一个人 | 每镜都引用角色资产图，并复述固定描述 |
| 服饰串味 | 新角色的脸 + 原角色的衣服 | 提示词里服饰描述**整体替换**，不要只改脸 |
| 体型不匹配 | 新角色体型与原构图冲突（穿模、被裁切） | 选体型接近的新角色，或调整构图描述 |

## 二、动作迁移

**改什么**：角色的动作。
**保留什么**：角色身份、场景、台词（镜头是否保留由用户定）。

### 需要的输入

- 动作来源，三选一：
  - **另一段视频**（最准）
  - 动作的文字描述
  - 姿态序列 / 骨骼数据（需要额外预处理）

### 技术路径

**动作来源是视频时**：把该视频作为视频参考输入，提示词里明确写"动作参考 `<Video 1>`"，并要求"角色的外观保持 `<Picture 1>` 不变，仅迁移 `<Video 1>` 中的动作与节奏"。

**动作来源是文字时**：把过渡描述里的**"中间运动"整段替换**为新动作描述。

**关键**：动作迁移通常**必须同时改写起始状态与结束状态**——因为换了动作，起点姿势和终点姿势都会变。只改中间运动会导致帧间接不上。

| 字段 | 1:1 复刻 | 动作迁移 |
|---|---|---|
| 起始状态 | 照抄源片 | **按新动作改写** |
| 中间运动 | 照抄源片 | **整段替换** |
| 结束状态 | 照抄源片 | **按新动作改写** |
| 角色/场景/光线 | 照抄 | **照抄（不动）** |

### 验证要点

- 新动作与场景**物理自洽**（不穿模、不悬空、与环境互动合理）
- 每段时长**容得下**新动作；容不下就要么拉长段时长（受模型上限约束）、要么简化动作
- 结束姿势能接到下一段的起始姿势

## 三、音色替换

**改什么**：配音的音色。
**保留什么**：台词内容、时间码、画面。

### 需要的输入

- 目标音色：参考音频样本 / TTS 音色库中的音色 / 音色文字描述（如"低沉男声、语速偏慢"）

### 技术路径（两条，优先 B）

**路径 A：让模型生成**
在提示词的声音描述字段写清新音色特征。H3 类模型是**音视频联合生成**的，音色由提示词决定——但可控性差，同一音色在不同段可能漂移。

**路径 B：后期替换（推荐）**
1. 用 `scripts/extract_subtitles.py` 拿到**台词文本与时间码**（若源片无字幕，从音频转写）
2. 用 TTS 按目标音色合成每条台词
3. 按时间码对轨替换；长度不匹配时优先微调语速，仍不齐则在句间补留白
4. 保留原片的**音乐与音效轨**，只替换人声（若原片人声与音乐混在一起，需要先分离）

### 验证要点

- 每条台词的**起止时刻与原片一致**（口型能对上）
- 音色在**全片前后一致**（同一音色库、同一参数）
- 原片的音乐/音效**没有被一起换掉**

### 常见风险

| 风险 | 表现 | 规避 |
|---|---|---|
| 口型对不上 | 画面上嘴在动但声音错位 | 严格按时间码对轨；必要时微调语速 |
| 音色漂移 | 前后段像两个人 | 固定音色库条目与参数，不要每段重选 |
| 情绪丢失 | 换音色后语气平淡 | 台词级别指定情绪；或保留原音频的节奏与停顿 |
| 源片无音轨 | 不存在"原音频"可替换 | 此时是**全新配音**，不是替换，需向用户说明 |

## 组合时的顺序与冲突

多项一起做时，**按下面的顺序处理**，并把冲突点讲给用户：

1. **资产层面先定**（角色替换、场景替换）——它们改的是资产库，影响后面所有描述
2. **再定动作**（动作迁移）——动作改了会影响段时长是否需要调整
3. **最后定音频**（音色替换）——它依赖台词时间码，而时间码在动作改动后可能变化

**已知冲突**：

| 冲突 | 说明 | 建议 |
|---|---|---|
| 角色替换 + 动作迁移 | 新角色做新动作，两个变量同时改，模型容易崩 | 分两步做：先出角色替换版，验收后再做动作迁移 |
| 动作迁移 + 音色替换 | 动作变了，台词原有的口型时间码就失效 | 先定动作，再按新动作重新排台词时间码 |
| 角色替换 + 保留原音色 | 新角色配原音色，观感可能割裂 | 提示用户这是有意为之还是漏配 |
| 全三项一起做 | 变量太多，一次生成很难验收 | **强烈建议拆成多轮**，每轮只加一个变量 |

## 交付说明必须写清

交付物的开头必须有一行**复刻模式**，让用户一眼看到这次做了什么变换：

```
复刻模式：1:1 完整复刻（原角色 / 原场景 / 原动作 / 原音频）
```
或
```
复刻模式：角色替换（CH-01 噜噜 → 新角色「阿吉」）+ 音色替换（低沉男声）
保留：动作时序 / 镜头运动 / 构图 / 场景 / 台词内容与时间码
```

以及一份**变换对照表**，逐镜说明变换前后：

| 镜 | 变换项 | 变换前 | 变换后 | 保持不变 |
|---|---|---|---|---|
| 01 | 角色 | 噜噜（橙色水豚） | 阿吉（灰色小狼） | 动作/镜头/场景 |
