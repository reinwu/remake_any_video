# 镜头语言术语速查表

分析画面（第四步）和撰写分镜脚本、制图提示词时，从这张表里挑词，不要自造说法或凭感觉翻译——
这样同一个视频里不同镜头的描述才会用词统一，产出的制图提示词也能直接被 Midjourney / 即梦 / 可灵
等工具的英文术语库正确理解。每一项都给出中文说法 + 对应英文（用于生图/生视频 prompt）。

## 一、景别 Shot Size（按人物入镜比例，从远到近）

| 中文 | 英文 | 说明 |
|---|---|---|
| 大远景 | Extreme Wide Shot (EWS) | 人物极小甚至不可见，强调环境/空间/氛围 |
| 远景 | Wide Shot (WS) / Long Shot | 人物完整+大量环境信息 |
| 全景 | Full Shot (FS) | 人物从头到脚完整入镜 |
| 中远景 | Medium Wide Shot (MWS) | 膝盖以上 |
| 中景 | Medium Shot (MS) | 腰部以上，最常见的对话镜头 |
| 中近景 | Medium Close-up (MCU) | 胸口以上 |
| 近景 | Close-up (CU) | 肩部以上，突出表情/情绪 |
| 特写 | Extreme Close-up (ECU) | 五官局部、眼睛、手部、物体细节 |

## 二、拍摄角度 Camera Angle

| 中文 | 英文 | 说明/情绪暗示 |
|---|---|---|
| 平视 | Eye-level | 中立、平等、真实 |
| 仰拍 | Low angle | 显得高大、有力量、压迫感 |
| 俯拍 | High angle | 显得渺小、脆弱、旁观视角 |
| 顶拍/鸟瞰 | Top-down / Bird's-eye view | 全局感、格局感，美食/穿搭类常用 |
| 荷兰角/斜角 | Dutch angle / Canted angle | 制造不安、失衡、紧张感 |

## 三、运镜 Camera Movement

| 中文 | 英文 | 说明 |
|---|---|---|
| 固定镜头 | Static shot / Locked-off shot | 三脚架不动 |
| 横摇 / 竖摇 | Pan / Tilt | 机位不动，镜头左右转/上下转 |
| 推镜 / 拉镜 | Dolly in / Dolly out (Push in / Pull out) | 机位物理前后移动，透视关系会变化 |
| 变焦推拉 | Zoom in / Zoom out | 只变焦距不移动机位，透视关系不变，和推拉镜质感不同，不要混用 |
| 跟拍 | Tracking shot / Follow shot | 跟随主体移动 |
| 手持 | Handheld | 略带晃动，增加真实感/纪实感/紧张感 |
| 稳定器运镜 | Gimbal / Steadicam shot | 平滑流畅的运动镜头，常见于运镜感强的短视频开场 |
| 空中/无人机 | Aerial shot / Drone shot | 大场景、地标、开场建立镜头常用 |
| 环绕 | Orbit shot / Arc shot | 围绕主体转动，突出产品/人物 |
| 甩镜 | Whip pan | 快速转向，常用于转场 |
| 一镜到底 | Long take / One-shot | 中间不剪辑，强调沉浸感 |

## 四、转场 Transition

| 中文 | 英文 | 说明 |
|---|---|---|
| 硬切 | Hard cut / Straight cut | 最常见，直接切换，短视频节奏感强 |
| 淡入/淡出 | Fade in / Fade out | 常用于开场/结尾 |
| 叠化 | Cross dissolve | 两画面交叉溶解，常表示时间流逝 |
| 匹配剪辑 | Match cut | 前后镜头某元素形状/动作相似，无缝衔接 |
| 遮挡转场 | Wipe transition / Object transition | 人或物遮挡镜头后切换到下一场景 |
| 跳切 | Jump cut | 同一机位内跳跃剪辑，Vlog/口播常用，强调信息密度 |
| 甩镜转场 | Whip pan transition | 用快速甩镜的运动模糊衔接两个镜头 |

## 五、光线 Lighting

| 中文 | 英文 | 说明 |
|---|---|---|
| 自然光 | Natural light | |
| 硬光 / 软光 | Hard light / Soft light | 硬光阴影锐利，软光过渡柔和 |
| 顺光 / 逆光 / 侧光 | Front light / Backlight / Side light | |
| 暖调 / 冷调 | Warm tone / Cool tone | 色温高低带来的情绪暗示 |
| 三点布光 | Three-point lighting (key/fill/back light) | 访谈、口播类标准布光 |
| 伦勃朗光 | Rembrandt lighting | 脸部一侧三角形高光，戏剧感 |
| 剪影 | Silhouette | 主体只见轮廓，背后强光源 |
| 丁达尔光/丁达尔效应 | God rays / Volumetric light | 光线穿过缝隙/雾气形成光柱 |

## 六、构图 Composition

| 中文 | 英文 | 说明 |
|---|---|---|
| 三分法 | Rule of thirds | 主体落在九宫格交点 |
| 对称构图 | Symmetry | 稳定、庄重、克制感 |
| 引导线 | Leading lines | 用线条引导视线到主体 |
| 框架式构图 | Framing | 用前景元素（门框/窗框）包裹主体 |
| 前景遮挡 | Foreground occlusion | 前景虚化物体制造层次感 |
| 负空间 | Negative space | 大面积留白突出主体/文案位置 |
| 浅景深/虚化 | Shallow depth of field / Bokeh | 背景虚化，突出主体，常见于美食/产品/人像 |

## 七、调色与风格 Color Grading & Visual Style

| 中文 | 英文 | 常见用途 |
|---|---|---|
| 电影感青橙调 | Teal and orange grade / Cinematic grade | 商业片、Vlog大片感 |
| 高对比黑白 | High-contrast black and white | 纪实、访谈、文艺 |
| 复古胶片感 | Vintage film look, film grain | 怀旧、文艺、旅拍 |
| 高饱和 | High saturation, vibrant colors | 电商、美妆、美食 |
| 低饱和/莫兰迪色 | Desaturated, muted tones, Morandi color palette | 氛围感、高级感、日系 |
| 赛博朋克霓虹 | Cyberpunk, neon lighting | 科技、夜景、潮流 |
| 日系清新 | Japanese-style, soft natural light, airy tone | 生活方式、家居、穿搭 |

## 使用建议

- 分镜脚本里的"景别""运镜""转场"三列，直接从上表挑中文词，保持全片统一。
- 制图提示词里对应的英文词，直接从上表右侧列复制，不要自己意译——这些是生图/生视频工具训练语料里出现频率最高、最能准确复现效果的标准表达。
- 如果画面中出现表里没有覆盖的手法（比如特定的滤镜插件效果、特殊转场特效），照实描述即可，不必强行套用术语。
