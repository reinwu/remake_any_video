# 参考图去字：为什么必须做，怎么做

## 问题

复刻时参考帧（锚点图、角色图、场景图）**必须不含任何文字**：

- **烧录字幕**：源片画面底部的中文字幕会被模型当成画面元素**照抄**，生成出一堆乱码汉字
- **常驻标题/水印**：短视频常见的左上角话题标题（如「当情侣一起出去吃饭：」）**每一帧都有**，
  躲不掉 —— 任何锚点都带着它
- **贴纸/角标/台标**：同理

**这不是"看着难看"的问题，是会被模型复制的问题。** 模型看到参考图里有字，就会在生成画面里
再画一遍，而它画的中文必然崩坏。

## 做法：量准范围 → 用邻域内容糊掉 → 后期重新叠加

### 第一步：量准文字范围（**不要凭感觉估**）

实测过一次教训：凭感觉估的标题框 `(0,0,700,110)` 只盖住了标题的左半，资产里仍残留「…去吃饭：」的
残字。而标题实际范围是 `x 85–1030, y 55–145`——**比我估的宽了一半**。

正确做法：**裁一块带坐标网格的放大图，目视量取**：

```bash
# 裁左上角并放大，再用脚本画上坐标网格
ffmpeg -y -ss <任意时刻> -i src.mp4 -frames:v 1 \
  -vf "crop=1400:240:0:0,scale=1400:240" title.png
```

```python
# 在图上画网格（每 100px 一条），保存后自己看图读数
for gx in range(0, 1401, 100):
    d.line([(gx, 0), (gx, im.height)], fill=(255, 50, 50))
    d.text((gx + 2, 2), str(gx), font=F, fill=(255, 110, 110))
```

**为什么不用亮像素/白字检测自动定位**：实测不可靠 —— 明亮背景（窗户、天花灯）会被全部算成"文字
墨迹"，标题区的并集直接变成整幅画面。

**字幕带的范围**可以用 `extract_subtitles.py` 自动定位的那条带作起点（它靠时域变化找，比较准），
再向外留边距 —— 但**横向要按全宽遮**，因为长句字幕会铺得很宽。

### 第二步：用邻域内容糊掉（不是涂黑）

```python
MASK_BOXES = [
    # (x0, y0, x1, y1, 填充来源)  坐标基于原片分辨率
    (40,  22, 1080,  178, "below"),   # 标题：取它下方同高的一条来填
    (0, 1170, 2560, 1370, "above"),   # 字幕带：取它上方同高的一条来填
]

def mask_text(path):
    im = Image.open(path).convert("RGB")
    W, H = im.size
    sx, sy = W / 2560.0, H / 1440.0          # 按原片分辨率换算
    for x0, y0, x1, y1, mode in MASK_BOXES:
        a, b = int(x0 * sx), int(y0 * sy)
        cx, cy = min(W, int(x1 * sx)), min(H, int(y1 * sy))
        bw, bh = cx - a, cy - b
        if bw < 2 or bh < 2:
            continue
        src = (im.crop((a, max(0, b - bh), cx, b)) if mode == "above"
               else im.crop((a, cy, cx, min(H, cy + bh))))
        src = src.resize((bw, bh)).filter(ImageFilter.GaussianBlur(14))
        im.paste(src, (a, b))
    im.save(path)
```

**要点**：

1. **取邻域同高的一条来填 + 高斯模糊**，不要涂纯色块 —— 纯色块在参考图里是明显的异物，
   模型可能把它当画面结构画出来
2. **跨分辨率复用**：遮罩框按原片分辨率定义，用比例换算到实际图片尺寸（锚点图通常会缩放）
3. **所有参考图都要过一遍**：锚点、角色、场景、道具、服装 —— 任何一张带字都会污染生成

### 第三步：后期把文字加回来

被遮掉的字幕与标题**改在成片后用 ASS 叠加**，与字幕同一个文件：

- 字幕用底部居中的 `Sub` 样式
- 常驻标题用左上角的 `Title` 样式，时间轴设为全片（`0:00:00.00` 到成片总长）

```ass
[V4+ Styles]
Style: Sub,Microsoft YaHei,34,&H00FFFFFF,&H00FFFFFF,&H00141414,...,2,40,40,18,1
Style: Title,Microsoft YaHei,34,&H0050D0FF,&H0050D0FF,&H00202020,...,7,20,20,14,1
;                                                      ↑ Alignment 7 = 左上角

[Events]
Dialogue: 0,0:00:00.00,0:00:01.77,Sub,牛服务员,0,0,0,,这是两位的位置，请慢用
Dialogue: 0,0:00:00.00,0:00:32.71,Title,,0,0,0,,当情侣一起出去吃饭：
```

这样**画面里一个错字都没有**，所有文字都是后期精确排版的原文字 ✅

## 检查清单

- [ ] 确认源片有没有**常驻**标题/水印（不只是字幕）—— 逐帧看左上/右上/底部
- [ ] 用**坐标网格放大图**量准每处文字的范围，不要凭感觉估
- [ ] 遮罩框**按原片分辨率定义**，用比例换算到每张参考图
- [ ] 用**邻域内容 + 高斯模糊**填充，不要涂纯色块
- [ ] **所有**参考图（锚点/角色/场景/道具/服装）都过一遍遮罩
- [ ] 重建后**逐张目视复查**：放大文字区，确认一个字都看不见
- [ ] 被遮掉的文字**在后期用同一个 .ass 加回来**（标题用左上角样式 + 全片时间轴）
- [ ] 用**视频片段**（不是单张静图）验证字幕渲染 —— 对静图用 `ass` 滤镜时时间戳恒为 0，
      永远只渲染第一条字幕，看不出真实时间轴

> **最后一条踩过坑**：用 `ffmpeg -i frame.png -vf ass=...` 测字幕，单张图没有时间轴，
> 滤镜按 t=0 渲染，于是任何时刻的测试都显示第一条字幕，看起来"时间全错"。
> 必须烧到视频上（`-i src.mp4 -vf "ass=...,scale=..."`）再抽帧比对。
