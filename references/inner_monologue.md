# 内心独白 vs 开口说话：必须区分，写法不同

## 为什么必须区分

**两者在同一部片里长得一样（都是底部字幕），但声画关系完全相反**：

| | 开口说话 | 内心独白 |
|---|---|---|
| **口型** | 嘴在**明显开合**（每个字都有形变） | 嘴**几乎不动**，或只是轻微表情变化 |
| **对象** | 对画面里的某个人说 | 说给自己听，**画面里没人回应** |
| **语义** | 称呼对方、提问、应答 | 自述、盘算、吐槽、心虚 |
| **画面动作** | 一般是静止对话 | **身体常常在做别的事**（站着、走路、翻菜单） |
| **声音质感** | 正常外放的对白 | 更近、更轻、更贴耳（"心里想的"） |

**把内心独白当成开口说话来写，模型会让角色一本正经地对着别人念心里话**——
口型对上了、但说话对象错了，整段的表演逻辑就崩了。

### 真实翻车案例

复刻一条 3D 卡通短片，全片 19 条字幕里：

| 类别 | 条数 | 例子 |
|---|---|---|
| 服务员对客人说的**真对白** | 2 条 | 「这是两位的位置，请慢用」「谢谢」 |
| **男主内心独白** | 7 条 | 「和噜妹坐一块」「碗摆不开」「菜也不好夹」「她想去上厕所也不方便」「我还是坐对面吧」「嘿嘿」「我考虑真周到~」 |
| **女主内心独白** | 6 条 | 「坐那么远」「又不能牵手」「说话又费劲」「他是不是不想和我坐在一起」… |
| 结尾两人**真对白** | 4 条 | 「宝贝」「这个菜你吃不吃」「随便」「啊？」 |

**19 条里有 13 条是内心独白** —— 也就是说**大部分内容根本不该张嘴**。
而当时的提示词把它们全写成了普通对白（`<Subject N> (Sx) says …`），
于是模型让男主对着女主大声念自己的心理活动。

**成因**：判定说话人时只看了"谁的嘴在动"。
内心独白时嘴角也会有细微表情变化，**在低分辨率的关键帧上很容易被误判成"在说话"**。

---

## 怎么判定（三步，按顺序）

### 第一步：口型的**幅度**

不要只看"嘴有没有动"，要看**动的幅度和节奏**：

| 表现 | 判定 |
|---|---|
| 嘴**大幅、有节奏地**开合，每个字都有形变 | 开口说话 |
| 嘴只是**轻微抽动/抿嘴/嘴角变化**，没有逐字形变 | **内心独白** |

> 实用判据：抽该条字幕时段的 4~6 帧，**量一下嘴部区域的帧间变化量**。
> 开口说话的帧间差明显高于独白。拿不准时，横向比较同一角色"确定在对人说话"的那条做基准。

### 第二步：**语义与对象**

| 特征 | 倾向 |
|---|---|
| 称呼对方（"宝贝""你…"）、提问后对方**有反应** | 开口说话 |
| 自述处境、第三人称提到在场的人（"**他**是不是不想…"） | **内心独白** |
| 抱怨、盘算、吐槽、心虚，画面里没人回应 | **内心独白** |

> **"他/她"指向在场的人**，是最强的独白信号 —— 当着对方的面不会用第三人称说他。

### 第三步：**画面里有没有人在听**

看该时段的**对白条**（多帧）：

- 说话者在说、**另一个人有聆听反应**（转头、点头、被说中后的表情变化）→ 开口说话
- 说话者在说、**另一个人毫无反应**，或者干脆**不在画面里** → 内心独白
- **在画面里但没人在说话**（口型都没动）→ **一定是内心独白或画外音**

## 怎么写进 H3 提示词

### 开口说话（和以前一样）

```
<Subject 1> (S1) says in a warm mid-pitched voice, using the voice timbre
referenced from <Audio 1>, <d>[Chinese] …</d>
```

### 内心独白（**关键区别**）

**三件事必须写出来：**

1. **这是内心独白**，不是对谁说
2. **嘴不动**（否则模型会让角色张嘴）
3. **身体在做什么**（独白期间的实际动作）

```
[Shot 1] <Subject 1> (S1) stands behind the booth, his back to the camera,
looking down at the table. The line is delivered as an interior monologue —
his mouth stays closed and no one in the frame reacts to it. Using the same
voice timbre referenced from <Audio 1>, but held closer, softer and slightly
breathy as an inner voice, he thinks, <d>[Chinese] 和噜妹坐一块</d>
```

要点拆解：

| 片段 | 作用 |
|---|---|
| `stands behind the booth, his back to the camera` | **身体状态**（独白时常在做别的事） |
| `delivered as an interior monologue` | **定性**：不是对白 |
| `his mouth stays closed` | **关掉口型**，防止模型让它张嘴 |
| `no one in the frame reacts to it` | 关掉聆听反应 |
| `held closer, softer and slightly breathy as an inner voice` | **声音质感**：内心化的处理 |
| `he thinks, <d>…</d>` | 用 `thinks` 而不是 `says` |

### 音色：可以与开口说话不同

内心独白和真实对白**可以用不同的音色参考**：

- **默认（推荐）**：**同一个 `<Audio N>`**，靠交付方式（更近、更轻、更贴耳）区分 ——
  角色仍听得出是同一个人，只是"在心里的声音"
- **可选**：给内心独白单独挂一个音色参考（`<Audio N>` 指向另一条音频），
  适合"内心声音与外在声音刻意不同"的设定（如内心更低沉/更怯懦）

无论哪种，都要在 `subject_definitions` 里把两个 `<Audio N>` 的角色分别写清：

```
<Audio 1> is the voice-timbre reference for <Subject 1> (S1), his spoken voice.
<Audio 2> is the voice-timbre reference for <Subject 1> (S1) as an interior
voice, used only for his inner monologue.
```

### 编号规则不变

`<Audio N>` 仍是**该段 `AUDIO_INSTRUCTION` 里第 N 个音频槽位**；
用几个就挂几个 —— **一段里既有对白又有独白时，两个槽位都要挂**。

## 检查清单

- [ ] **每条字幕都判过"开口说话 / 内心独白"**，不默认按对白处理
- [ ] 判定同时用了**口型幅度**与**语义对象**，不是只看嘴有没有动
- [ ] 用了第三人称提到在场角色（"他是不是…"）的句子，复查过是不是独白
- [ ] 内心独白的段落里写了 **`mouth stays closed`**（或等价的明确表述）
- [ ] 内心独白用 **`thinks`** 而不是 `says`
- [ ] 内心独白段落写了 **`no one reacts`**，关掉聆听反应
- [ ] 内心独白写了**身体在做什么**（站着/走路/翻菜单），不让人物呆立
- [ ] 交付方式写了**更近/更轻/更贴耳**那类内心化描述
- [ ] 若用了独立音色，两条 `<Audio N>` 的角色在 `subject_definitions` 里分别写清
- [ ] 一条字幕**不能既当对白又当独白**；跨镜头的独白按发声事件归属到唯一一段

> ⚠️ **模型对"嘴不动"是软约束**：写清楚能显著减少误张嘴，但不保证完全不动。
> 试跑段要专门抽查独白段落的口型，不合格就加强措辞（"his lips remain pressed together"）。
