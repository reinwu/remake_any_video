# 关键帧序列描述：让帧与帧之间真正连贯

## 为什么必须"先看运动，再写描述"

从关键帧抽出的**一张**静态图，只能说明"这一帧长什么样"。它**说明不了发生了什么**：

- **动作弧丢失** —— 主体从哪里来、做了什么、到哪里去，全都不在图里
- **因果关系丢失** —— 为什么会有下一个状态
- **说话人无法判断** —— 谁在说话取决于**口型**，那是帧间的变化
- **入场/出场丢失** —— 主体在镜头中段才进入画面这种事，首帧完全看不出来

### 真实翻车案例（务必引以为戒）

复刻一条 3D 卡通短片时，全程只用"每镜一张静帧"写提示词，结果：

| 现象 | 事实 | 静帧方式为什么必然出错 |
|---|---|---|
| **整段剧情缺失** | 原片第 2 个镜头是「噜噜**追蝴蝶**，**掉进树洞里**」 | 锚点帧只拍到"噜噜在巨树前的背影"——追蝴蝶与掉落都是**帧间发生的事件**，静帧里根本不存在 |
| **说话人搞反** | 大量本该**大蘑菇伙伴**说的台词，复刻里变成**噜噜**在说 | 静帧看不出谁在动嘴，只能靠"谁在画面里"猜，猜错是必然 |

**结论：写任何动作或对白描述之前，必须先看运动。**

## 第一层：资产库（先建立，全程复用并引用）

**只写一份统一的文字描述是不够的。** 文字只能统一"措辞"，**给不了模型任何视觉锚点**。
模型每一帧都是独立生成的，没有共同的图像参照，同一件衣服照样会变成三种样子。

**必须建立资产库，并在每一条提示词里显式引用。**

### 类型（五类）

| 类型 | 收什么 | 备注 |
|---|---|---|
| **角色** | 主要角色 | 外观锚点要写到"照着能画出来" |
| **服装** | 角色身上**会被反复看到**的服饰（形制+颜色+材质） | **跨镜最容易漂移的就是它**，单独建条目便于逐镜核对 |
| **道具** | 剧情里起作用的关键物件（反复出现或推动情节） | 道具换样子观众立刻察觉 |
| **场景** | 反复出现的环境 | 记光源方向与色温 |
| **风格** | 全片统一的渲染风格 | 只传递色调与笔触，不锁具体内容 |

> ⚠️ **封装工具的槽位类型可能更少**。例如某导演台只支持 `角色/场景/道具/分镜/其他`——
> **没有「服装」**。这种情况下，服装资产在引用时挂到 `角色` 或 `其他` 槽位，
> 但**资产库里仍单独建条目**，用于逐镜核对一致性。

### 结构

为每条资产建：**一张参考图 + 一段固定描述 + 一个固定 ID**。

| 资产ID | 类型 | 名称 | 参考图 | 固定描述（外观锚点） | 出现镜头 |
|---|---|---|---|---|---|
| CH-01 | 角色 | 噜噜 | `资产库/角色A.png` | 橙色水豚状小动物，大头小耳、圆滚滚体型、浅色肚皮、黑豆眼 | 01,02,03… |
| CS-01 | 服装 | 噜噜妹的粉背带裤 | `资产库/服装A.png` | 粉色背带裤，宽背带、两颗圆形纽扣、棉质 | 03,05,06,07 |
| PR-01 | 道具 | 行李箱 | `资产库/道具A.png` | 青绿色硬壳行李箱，黑色提手、四角黑色滚轮 | 05,06 |
| SC-01 | 场景 | 卧室 | `资产库/场景B.png` | 木床+浅粉被褥、右侧亮窗、米色窗帘 | 05 |
| ST-01 | 风格 | 全片基调 | `资产库/风格A.png` | 3D 卡通渲染、圆润、明亮饱和、暖调 | 全片 |

### 参考图从哪来

1. **首选：直接从源片抽**——找该角色/道具/场景**最清晰、遮挡最少**的那一帧裁出来
2. 次选：源片里始终没有干净帧时，按固定描述单独生成一张三视图/正面立绘
3. **必须避开字幕**：字幕会被模型当成画面元素照抄。用强边缘检测扫字幕带，
   把占比 ≥ 0.005 的帧换掉（在同一镜头内换一帧通常就能避开）

### 引用规则（硬要求）

**每一条提示词都必须声明引用了哪些资产** —— 逐帧的与过渡的都不能漏。
只在开头说一次"角色见资产库"是没用的：**提示词会被单独送去生成，模型看不到上下文**。

按工具机制写：图像参考用 `<Picture i>`（顺序与槽位一致）、角色/场景/服装/道具/风格
用 `<Subject N>` 定义并在正文引用。**引用时同时复述资产的固定描述**——
图像锚点负责"像不像"，文字描述负责"别漏掉特征"。

**交付要求**：给出**资产引用表**，让用户能核对每个镜头引用了哪些资产。

## 第二层：逐帧状态描述

每一帧写这几项，**用资产库里的固定描述原词**：

| 维度 | 内容 |
|---|---|
| 景别 | 特写/近景/中景/全景/远景/大远景（术语取 `references/shot_glossary.md`） |
| 角度与构图 | 平视/仰拍/俯拍；三分法/对称/引导线/框架式/前景遮挡 |
| **主体状态** | 谁、在画面哪个位置、朝向、姿态、表情 |
| 环境状态 | 光线、天气、氛围、环境动态 |
| 画面文字 | 字幕/标题/贴纸的内容与位置 |
| **引用资产** | 本帧引用的资产 ID（每帧都要写，不能省略） |

**"主体状态"要写位置和朝向**——这是判断相邻帧能否接上的主要依据。

## 第三层：相邻帧过渡与动作弧（核心）

**每两个相邻关键帧之间写一条。** 这是让画面连贯的关键，也是最容易被跳过的一层。

先按 `scripts/extract_shot_frames.py` 抽多帧做成**动作条**逐条看过，再写下面的字段：

| 字段 | 内容 |
|---|---|
| 起始状态 | 上一帧的**结束状态** |
| **事件** | 这一段**发生了什么**（追、掉、跑、抱、递、转身…）——**动作弧的灵魂** |
| **中间运动** | 主体位移与动作 + **镜头运动（类型 + 速度 + 幅度）** + 光线变化 |
| 结束状态 | 下一帧的**起始状态** |
| **入场/出场** | 有没有主体在镜头中途进入或离开画面 |
| 对话 | 说话人 + 内容 + 起止时刻 |
| **引用资产** | 本段引用的资产 ID 及槽位写法 |
| **不变量** | 过渡期间必须保持不变的元素 |

### 写法要点

**1. 事件要写得让模型能演**：`crouches and springs after the butterfly` 而不是 `is in a forest`。
写成"巨树前的森林空地"是**画面**，写成"追蝴蝶时失足掉进树洞"才是**事件**。

**2. 用"从…到…"句式**把变化量写出来：位置、姿态、情绪、构图都可量化。

**3. 运镜写"类型 + 速度 + 幅度"**，不要零信息量的词：

> ❌ 镜头缓缓移动　　✅ 镜头固定不动；或：镜头以极缓速度向前推进约半个身位，匀速无停顿

**4. 明确写出"不变量"**：角色服饰形制与配色、场景结构、光源方向。
配套写"可变量"（位置、姿态、表情）。**服饰是最容易漂移的一项**。

**5. 一段过渡只描述一个连续镜头内的变化。** 原片在这里**切了镜**的，必须标注"此处为硬切"
并拆成**两条**过渡描述——糊成一条会让模型把两个空间叠在一起。

**6. 每条过渡都要声明引用了哪些资产**，并同时复述资产的固定描述。

### 输出格式

| # | 起始帧 | 结束帧 | 时长 | 起始状态 | **事件** | 中间运动 | 结束状态 | 镜头 | 对话 | 引用资产 | 不变量 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 1 | KF01 | KF02 | 2.48s | … | 追蝴蝶 | … | … | 固定 | 噜噜：… | CH-01, SC-01 | 服饰/光源 |

## 说话人判断（口型法，**不许猜**）

**不要凭"谁在画面里"猜。** 用 `extract_shot_frames.py --dialogue` 抽出的对白条判断：

1. **口型比对**：字幕时间段内，说话者的嘴在帧间有**明显开合形变**，听者基本不动
2. **语义交叉验证**：问句之后紧接着的那句，多半是**另一个人**说的
3. **画外音**：全程没有角色动嘴 → 标 `off-screen`，不要硬安到画面里的角色身上
4. **一句内换人**：嘴部形变先出现在 A 后出现在 B → 中途换了说话人

**判断不了就如实标注"说话人待确认"，不要编。** 安错人会让整段对白的音画关系全错。

## 台词分配表（防重复）

给多段分配台词前，先建这张表并**逐条核对唯一性**：

| 台词 | 所属段 | 说话人 | 依据（时间码 / 口型） |
|---|---|---|---|
| 你能不能不要再这样？ | 01 | 噜噜 (S1) | 1.50–4.25s，画面中他的嘴在开合 |

分配完立即复检：**统计每条台词出现的次数，任何 > 1 的都要处理掉**。
反复出现的台词会让成片里同一句话被说好几遍——最容易被用户一眼听出来的低级错误。

**脚本会自动查**：`python scripts/qc_check.py --script <剧本>` 会逐条列出重复对白（含段号）。

## 与分段规划的衔接

**工作流顺序很重要**：先做分段规划（`plan_segments.py`），**再按分段表的锚点时间抽关键帧**，
**最后写提示词**——不要按固定间隔均匀抽、更不要先写词后抽帧。

均匀抽出来的关键帧几乎不会落在段边界上，结果是**每条过渡都跨段**，描述与生成段对不上；
而**先写词后抽帧**会让文字与图像直接矛盾（实测过：这批段的构图遵循度只有 0.17，
而顺序正确的批次是 0.37）。

正确顺序：

1. `extract_shots.sh` 做场景检测、拿到切点
2. `plan_segments.py` 按切点 + 模型时长约束定出分段表
3. **按分段表再抽一次关键帧**：每段的 `anchor_time` 一张；段内含多个源片镜头的，每个镜头各抽一张
4. `extract_shot_frames.py` 抽动作条与对白条，**逐条看过**
5. 写三层描述 + 动作弧 + 说话人
6. 写提示词（一个生成段 = 该段覆盖的所有过渡描述按顺序串联）

**一段含多个源片镜头时**：若工作流支持多镜头时间轴就按镜头分别写；若只支持"一个提示词出一段"，
则把多个镜头**改写成一条连续运动**，**绝不能并列罗列几组独立画面**。

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| **只对单帧写描述** | 动作弧全丢，剧情缺失 | 先看动作条，写动作弧 |
| **只描述画面不描述事件** | 生成出来是没有情节的空镜 | 必写"事件"字段 |
| **凭"谁在画面里"猜说话人** | 台词安错人，音画关系全错 | 口型法 + 语义交叉验证 |
| **同一台词分配给多个段** | 成片里同一句被说好几遍 | 先建分配表，分配后复检次数 |
| **画外音硬安到画面角色身上** | 角色说了自己没说的话 | 标 `off-screen` |
| **只写文字台账、不建资产库** | 措辞统一了，但没有视觉锚点 | 建资产库（参考图+描述+ID）并逐条引用 |
| **提示词里不引用资产** | 该镜一致性崩坏 | 每条静态帧与过渡都显式声明引用的资产 |
| **服装/道具不单独建条目** | 换镜后衣服/道具变样 | 服装、道具各建资产，逐镜核对 |
| **不写"不变量"** | 服饰、场景、光源在段间漂移 | 每条过渡都列出不变量 |
| **把多个镜头写成并列描述** | 模型把多组内容叠在一张画面 | 串成一条连续运动，或按镜头分段 |
| **运镜写"缓缓移动"** | 模型自由发挥，运镜失控 | 写类型+速度+幅度，或直接写"固定" |
| **每帧重新措辞** | 同一角色被描述成不同东西 | 复用资产库的固定描述原词 |
| **忽略原片切点** | 两个空间被糊成一次连续运动 | 标注硬切，拆成两条过渡 |
| **参考帧带字幕** | 模型把字幕照抄进画面 | 抽帧时检测字幕带并换帧 |
| **先写提示词后抽锚点** | 文字与图像矛盾，构图跑偏 | 严格按「分段表 → 锚点 → 提示词」顺序 |

## 检查清单

**资产与引用**
- [ ] 每个关键**角色、服装、道具、场景**都有资产条目（参考图 + 固定描述 + ID）
- [ ] 参考图**优先取自源片**最清晰、遮挡最少的那一帧，且**避开字幕**
- [ ] **服装**单独建条目（最常见的漂移项）
- [ ] **道具**单独建条目（剧情关键物件）
- [ ] 每条**逐帧提示词**都声明了引用的资产 ID 与槽位写法
- [ ] 每条**过渡提示词**都声明了引用的资产 ID 与槽位写法
- [ ] 引用时**同时复述资产固定描述**，不是只写"见图 1"
- [ ] 交付物里有**资产引用表**，可逐镜核对

**动作与说话人**
- [ ] 每个镜头都抽了**多帧**（≥4；短镜 <1s 提到 6，长镜 >8s 提到 6~8）并**逐条看过**动作条
- [ ] 每个镜头都写了**动作弧**（起止状态 + 中间运动 + **事件** + 入场/出场）
- [ ] 每条对白的**说话人经过口型判断**，不是靠猜
- [ ] 画外音都标了 `off-screen`
- [ ] **台词分配表已建立**，且复检确认**每条台词只出现一次**

**描述完整性**
- [ ] 资产库里的每个条目，在全文中的称呼与外观描述完全一致
- [ ] 每两个相邻关键帧之间都有过渡描述
- [ ] 每条过渡的结束状态与下一帧的起始状态一致
- [ ] 每条过渡都写了**不变量**
- [ ] 原片切点处都标注了硬切（拆成两条而非糊成一条）
- [ ] 运镜描述都含速度与幅度，没有"缓缓移动"这类空词
- [ ] 对话都标了说话人与起止时刻
